models.py if i add phone_num to our db when working in swagger ui while authorozing internal server error 500 will be thrown.

Alembic helps you manage changes to your database schema over time—such as creating tables, adding columns, or modifying constraints—without losing data.
Track schema versions (like Git, but for databases)

-Apply updates incrementally instead of recreating the database

-Rollback changes safely if something breaks

-Keep database schema in sync with your SQLAlchemy models

*Key things Alembic does

1.Initialize a new,hgmneric env
code: alembic init <folder name>

after initialzing two things will appear:
-albembic.ini:congig info
-alembic directory: all env properties for albemic,all rev of application, where you can call the migration for upgrading and downgrading.

2.Creates a revision FILE where we can write upgrade code. Each new revision will have a revision id.
code:alembic revision  -m "msg"



3.Run our upgrade migration to our database:
alembic upgrade <revision #>

4.Run our downgrade migration to our database:
alembic downgrade -1


*gpt
1.Generates migration files (revision files)

2.Applies migrations using:

code:alembic upgrade head


3.Can auto-detect model changes:
code:alembic revision --autogenerate -m "add users table"

*downgrade:
| Goal                    | Command                           |
| ----------------------- | --------------------------------- |
| Revert last migration   | `alembic downgrade -1`            |
| Revert N migrations     | `alembic downgrade -N`            |
| Go to specific revision | `alembic downgrade <revision_id>` |
| Remove everything       | `alembic downgrade base`          |
| Reapply all             | `alembic upgrade head`            |
| See history             | `alembic history`                 |
| Current revision        | `alembic current`                 |

Explanation:
1️⃣ How Alembic identifies migrations

Each migration has a revision ID, like:

revision = "3f9a2c7d1a21"
down_revision = "1b4e6c8f9d02"


This forms a linear chain (or tree).

2️⃣ Downgrade to a SPECIFIC revision (most common)
Step 1: See migration history
alembic history


Example output:

1b4e6c8f9d02 -> 3f9a2c7d1a21 (add phone_number)
3a9c1e22d123 -> 1b4e6c8f9d02 (create users table)

Step 2: Downgrade to the revision you want
alembic downgrade 3a9c1e22d123


👉 This will:

Undo all migrations AFTER that revision

Stop exactly at 3a9c1e22d123

✅ Why ModuleNotFoundError: No module named 'main' happens

Python resolves imports using sys.path, which includes:

The current working directory

Installed site-packages

Paths added via PYTHONPATH

When you write:

import main


Python looks for:

main.py in the current directory, or

a package named main inside sys.path

If it can’t find either → ❌ ModuleNotFoundError

✅ Role of __init__.py
__init__.py tells Python:
"This directory is a package"


It does NOT:

define the project root

automatically expose child modules

fix import paths by itself

It only allows imports relative to that package.
